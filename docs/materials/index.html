Какие материалы нужны для сайта

Сайт собран и работает — сейчас в нём демонстрационные тексты и фотографии, взятые со старого сайта. Ниже по каждому разделу перечислено, что нужно прислать, чтобы заменить их на настоящие. Разделы независимы: можно присылать по частям, в любом порядке.

Фотографии

JPG или PNG, оригиналы без сжатия и без водяных знаков. Обрезать и подгонять размер не нужно — это сделаем мы.

Тексты

Word, Google Docs или просто сообщением. Главное — подписать, к какому разделу относится текст.

Как передать

Папкой на Google Диске или WeTransfer. Внутри — подпапки по названиям разделов из этого документа.

Переводы

Сайт работает на трёх языках. Если английской и кыргызской версий текста нет — пришлите русскую, переведём сами.

03

Номера и жильё

Каталог /rooms/, карточка каждой категории, поиск при бронировании

Самый объёмный раздел. Нужен список всех категорий размещения — номера, коттеджи, виллы, юрты. По каждой категории заполняется одна карточка.

Название категории
Как в прайсе: «Стандарт», «Полулюкс», «Коттедж у озера».
для запуска
Тип размещения
К какому типу относится: стандарт, полулюкс, люкс, делюкс, президентский, семейный, коттедж, вилла, юрта. Нужно для фильтра в каталоге.
для запуска
Вместимость
Максимум взрослых и максимум детей. По этим числам работает поиск по количеству гостей.
для запуска
Площадь, комнаты, кровати
Площадь в м², число комнат, состав спальных мест — например, «1 двуспальная + 2 односпальные».
для запуска
Цена за ночь
Базовая цена в сомах — показывается как «от … сом / ночь», пока гость не выбрал даты.
для запуска
Сколько номеров в категории
Общее количество. Пока не подключена система управления отелем, по этому числу считается наличие свободных мест.
для запуска
Краткое описаниедо 500 знаков
Одно-два предложения для карточки в каталоге.
для запуска
Полное описание
Развёрнутый текст для страницы категории: вид из окна, особенности, что входит в стоимость.
можно позже
Фотографии4–8 на категорию
Первая станет обложкой. Горизонтальные, от 1600×1067. Желательно: общий вид, кровать, санузел, вид из окна.
для запуска
Список удобств
Что есть в номере: Wi-Fi, кондиционер, балкон, сейф, мини-бар и так далее. Пришлите общий список по всем категориям — отметим, что к чему относится.
для запуска
Если категорий много — удобнее прислать одной таблицей: строка на категорию, столбцы по пунктам выше. Фотографии — папкой, названной по категории.

13

Доступы и интеграции

Это не контент, а доступы к сторонним сервисам. Без них соответствующие функции сайта работают в упрощённом режиме или не работают вовсе.

Shelterсистема управления отелем
Адрес сервера, ключ доступа к интерфейсу и код отеля. Пока не подключено, свободные номера считаются по числу из карточки категории, а не по реальной загрузке.
доступ
FreedomPayприём оплаты картой
Номер магазина и секретный ключ. До подключения гость оставляет заявку, а оплату подтверждает менеджер.
доступ
Google Placesотзывы из Google
Ключ доступа и идентификатор карточки курорта. Нужен аккаунт Google Cloud с привязанной картой — бесплатного лимита хватает. Даёт до 5 свежих отзывов, обновление раз в сутки.
доступ
2ГИСотзывы из 2ГИС
Ключ выдаётся только по партнёрскому договору с 2ГИС. Пока его нет, отзывы добавляются вручную со ссылкой на оригинал.
доступ
Почта для отправки писем
Ящик, с которого сайт отправляет подтверждения броней: адрес, пароль приложения и сервер. Лучше отдельный ящик вида noreply@, а не личный.
для запуска
Аналитика
Идентификаторы Google Analytics и Яндекс.Метрики, код подтверждения Google Search Console. Если счётчиков нет — заведём.
можно позже
Telegram-уведомления
Если хотите получать заявки в Telegram — создадим бота, от вас нужен только список получателей.
можно позже
Домен
Доступ к управлению доменом курорта, чтобы направить его на новый сайт. Сейчас сайт работает на временном адресе.
для запуска
